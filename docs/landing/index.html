Sans les vraies données.

Sosie turns a mysqldump dump into a faithful copy of your production database: same structure, same volume, same consistency, without a single real piece of personal data surviving. One command. Zero servers. Safe by default. Sosie transforme un dump mysqldump en une copie fidèle de ta prod : même structure, même volume, même cohérence, mais sans qu'une seule donnée personnelle réelle n'y survive. Une commande. Zéro serveur. Sûr par défaut.

Everyone does it. Nobody is proud of it. And every alternative is worse.Tout le monde le fait. Personne n'en est fier. Et les alternatives sont toutes pires.

Safe by defaultSûr par défaut

The tool refuses to run if a column that looks like personal data has no explicit rule. Forgetting becomes impossible by design, not by discipline.L'outil refuse de tourner si une colonne qui ressemble à une donnée personnelle n'a pas de règle explicite. L'oubli devient impossible par construction, pas par discipline.

Set up in minutesSetup en quelques minutes

sosie init scans the schema and the content of your dump, then generates a config already filled in for everything obvious. You only decide the ambiguous cases.sosie init scanne le schéma et le contenu de ton dump, puis génère une config déjà remplie pour tout ce qui est évident. Tu ne tranches que les cas ambigus.

Streaming: the dump is never loaded into memoryStreaming : le dump n'est jamais chargé en mémoire

Processed statement by statement: 1 GB and 17 million rows in ~30 s, under 100 MB of RAM. Only the deduplication of UNIQUE columns grows with the data. On a laptop, in CI, in a cron job.Traité instruction par instruction : 1 Go et 17 millions de lignes en ~30 s, sous 100 Mo de RAM. Seule la déduplication des colonnes UNIQUE grandit avec les données. Sur un laptop, en CI, dans un cron.

Consistency across tablesCohérence garantie entre les tables

In pseudonymize mode, the same input value always gives the same fake value: in every table, and from one export to the next. Joins hold.En mode pseudonymize, la même valeur d'entrée donne toujours la même fausse valeur : dans toutes les tables, et d'un export à l'autre. Les jointures tiennent.

UNIQUE and PRIMARY KEY columns stay unique after transformation. The import succeeds on the first try, with no duplicate errors.Les colonnes UNIQUE et PRIMARY KEY restent uniques après transformation. L'import passe du premier coup, sans erreur de doublon.

A clear summary at the end of the run and a JSON file in .sosie/: counters only, never a real value, not even by accident. Auditable, versionable.Un compte-rendu clair en fin d'exécution et un JSON dans .sosie/ : uniquement des compteurs, jamais une valeur réelle, même par accident. Auditable, versionnable.

A single binary, no server, no account, no upload. It pipes like mysqldump itself, wherever your dump already runs.Un binaire, pas de serveur, pas de compte, pas d'upload. Ça se pipe comme mysqldump lui-même, là où tourne déjà ton dump.

Byte-exact round-tripRound-trip byte à byte

Sosie makes sure of it, in one command, without you having to think twice. Try it on your next dump.Sosie s'en assure, en une commande, sans que tu aies à y penser deux fois. Essaie-le sur ton prochain dump.

$ git clone https://gitlab.com/mlejeune/sosie.git && cd sosie
$ cargo build --release
$ ./target/release/sosie init --from dump.sql --out sosie.yaml
$ ./target/release/sosie check --from dump.sql --config sosie.yaml
# check OK: 6 tables, no sensitive column without a rule.
